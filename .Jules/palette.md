## 2026-01-05 - Root Status Page
**Learning:** Adding a simple, accessible HTML status page at the root URL ('/') of an API service significantly improves the developer experience (DX) and UX. It provides immediate visual confirmation that the service is running, rather than a confusing 404 error.
**Action:** When building API services, always include a root handler that returns a human-readable status page with basic info (version, status).
