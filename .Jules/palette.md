## 2024-05-23 - Added Accessible Landing Page
**Learning:** Even purely API-based services benefit significantly from a simple, accessible landing page at the root URL. It confirms system status and provides immediate guidance, turning a confusing 404 into a helpful onboarding moment.
**Action:** Always verify the root endpoint (`/`) of an API service and add a status/welcome page if one is missing. Use semantic HTML and accessible status indicators.
