## 2026-01-18 - Embedded Status Pages
**Learning:** For single-file Go handlers serving HTML, inline SVGs with `aria-label` are superior to emoji or external assets. They ensure consistent rendering and accessibility without extra network requests or build steps.
**Action:** Use the `Status: Operational` SVG pattern (Circle Check) with `#4ade80` on `#111` bg for all future system status indicators.
