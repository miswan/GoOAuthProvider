## 2024-03-24 - API Root Status Page
**Learning:** For backend services, the "User Experience" starts at the root URL. Providing a visual "System Operational" page instead of a 404 or JSON error gives immediate, reassuring feedback to developers and administrators.
**Action:** Always verify if the root endpoint `/` is handled in API services and implement a lightweight, accessible HTML status page if it's missing. Use dark mode and system fonts to align with developer preferences.
