## 2024-05-23 - Discovery of Headless UX Opportunities
**Learning:** In a headless API backend without a traditional frontend, UX opportunities exist in the "User Facing" endpoints of protocols like OAuth2. Specifically, the Authorization Endpoint is meant to be rendered in a browser.
**Action:** When working on API-only projects, look for endpoints that interact with user agents (browsers) and ensure they provide a proper HTML experience instead of raw JSON.
