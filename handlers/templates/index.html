OAuth2 Provider

Operational

Welcome to the OAuth2 Provider service. This system handles user authentication and authorization securely.

Available Endpoints

  • Authorization
    GET /authorize

    Initiates the OAuth2 authorization flow.

  • Token Exchange
    POST /token

    Exchanges authorization code for access token.

  • User Info
    GET /userinfo

    Retrieves information about the authenticated user.

For more information, please refer to the API Documentation.
